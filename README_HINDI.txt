VOICE TO BILL - GROCERY SHOP MANAGEMENT SYSTEM

CHALANE KA TARIKA:
1. ZIP file ko Extract All karein.
2. Computer mein Python 3 installed hona chahiye.
3. START_PROJECT.bat par double-click karein.
4. Chrome mein http://localhost:8000 khul jayega.
5. Project band karne ke liye khuli hui black CMD window mein Ctrl + C dabayein.

IMPORTANT:
- index.html aur app.py ek hi folder mein rehne chahiye.
- Internet ki zaroorat nahi; project local computer par chalta hai.
- data.json aur bills folder project chalne par apne aap banenge.
- Voice input ke liye Chrome mein microphone permission Allow karein.
- Agar Python command nahi chalti, Python 3 install karke Add Python to PATH select karein.
